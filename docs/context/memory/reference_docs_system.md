The documentation system for Orbitae lives in `docs/`:

- `docs/PRODUCT.md` — Product spec, pricing, features by tier, success metrics
- `docs/ROADMAP.md` — Phase 1/2/3 development roadmap with checkboxes
- `docs/BRAINSTORM.md` — Every idea discussed, with ACCEPTED/REJECTED/DEFERRED status and reasoning
- `docs/COMPETITIVE.md` — Competitive analysis (BridgeMind, Warp, Cursor, etc.)
- `docs/ARCHITECTURE.md` — System architecture, module structure, data flows
- `docs/DECISIONS.md` — Technical decision log (ADR-style)
- `docs/MARKET.md` — Market intelligence, pricing benchmarks, distribution channels

`CLAUDE.md` at project root contains coding standards, tech stack, and project structure.

New brainstormed ideas go in BRAINSTORM.md. Technical decisions go in DECISIONS.md. All docs are cross-referenced.
